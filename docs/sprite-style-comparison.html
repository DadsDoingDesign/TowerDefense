Why only five are shown as pixels

This sandbox's network reaches GitHub only. DCSS, Kenney, LPC, Tiny Swords and 0x72 are hosted on GitHub — or mirrored there under CC0 — so I pulled their real art. The other fifteen live on itch.io, OpenGameArt, kenney.nl and CraftPix, which the proxy blocks, so they're catalogued with links instead of pixels.

To add any download-only pack: grab it, drop the PNGs into public/assets/sprites/<pack>/ using the same role names (fighter / rogue / mystic / grunt / …), and registering the theme is a one-liner. The five ✓ styles I can wire in end-to-end right now — Kenney (flat vector) and LPC (16-bit RPG) would give you two art directions genuinely distinct from the five DCSS biomes already in the game.
